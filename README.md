# 🎓 EFP — Edu Final Project

### Education & Data Analysis Assistant

Pelajar, mahasiswa, guru, dosen, serta pengguna umum yang membutuhkan bantuan dalam proses pembelajaran dan analisis data. EFP membantu pengguna memahami materi pendidikan, pemrograman, Data Science, Artificial Intelligence, serta melakukan analisis dokumen dan dataset seperti Excel atau CSV dengan bantuan AI.
